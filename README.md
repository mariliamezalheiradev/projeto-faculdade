# FlowSalon 💈✨

FlowSalon é um sistema web desenvolvido como projeto acadêmico para auxiliar salões de beleza e barbearias na organização de agendamentos, clientes, serviços e profissionais.

O projeto foi criado com foco em uma interface moderna, tema dark neon e funcionalidades práticas para simular a rotina administrativa de um salão.


## Sobre o projeto

O FlowSalon permite que salões realizem cadastro, login administrativo, controle de agenda, cadastro de clientes, serviços e profissionais, além de oferecer uma tela externa para agendamento de horários.

A proposta do sistema é facilitar a gestão do salão, trazendo mais organização, praticidade e uma melhor experiência tanto para administradores quanto para clientes.


## Funcionalidades

- Página inicial com apresentação do sistema
- Cadastro de salão
- Login administrativo
- Dashboard com visão geral do salão
- Gestão de agendamentos
- Cadastro e busca de clientes
- Cadastro de serviços
- Cadastro de profissionais
- Tela externa de agendamento para clientes
- Integração com API ViaCEP
- Armazenamento de dados com LocalStorage
- Página com apresentação da equipe
